# Tasker

Приложение для постановки и управления задачами.

## Основная идея

Быстро создавать задачи через веб-интерфейс,
а в дальнейшем — через Telegram и голосовой ввод.

## MVP

- [ ] Регистрация / авторизация
- [ ] Создание задачи
- [ ] Редактирование задачи
- [ ] Удаление задачи
- [ ] Выполнение задачи
- [ ] Просмотр задач по датам
- [ ] Календарь
